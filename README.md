## 简介
这是一款基于Android系统模拟定位API，实现的模拟定位APP

目前支持市面上大部分应用程序的模拟定位，包括钉钉打卡，腾讯系应用会检测是否使用了模拟定位，故而腾讯系应用大部分都不支持。

钉钉目前会检测是否开启了开发者模式，不能打卡的话请使用旧版本钉钉。
